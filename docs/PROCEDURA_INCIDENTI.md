# Procedura per le violazioni di sicurezza (art. 33–34 GDPR)

1. **Rilevare** (allarme, segnalazione a office@core829.net, esito «Verifica integrità» negativo): registrare data/ora di conoscenza. Da quel momento decorrono **72 ore**.
2. **Contenere:** revocare chiavi (`SUPPORT_SIGNING_SECRET`, token), bloccare account, sospendere download; conservare i log (`auditLog`).
3. **Valutare** il rischio per le persone: quali dati, quanti interessati, probabilità di danno.
4. **Notificare l'ANSPDCP** (dataprotection.ro) entro 72 h se il rischio non è improbabile; se tardi, motivare il ritardo.
5. **Informare gli interessati** senza ritardo se il rischio è elevato; informare i clienti per cui CORE829 è responsabile (art. 33.2).
6. **Registrare** l'evento nel registro delle violazioni (anche se non notificato): fatti, effetti, rimedi.
7. **Se rientra in NIS2:** preavviso entro 24 h, notifica entro 72 h, relazione finale entro 1 mese (autorità: DNSC).
8. **Dopo l'incidente:** analisi delle cause e correzione, aggiornamento di questi documenti.
