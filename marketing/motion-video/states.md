Hold note: no state contains a paragraph or quote (longest copy is two short disclaimer lines),
so no 4–6 s hold was needed in the 14 s loop.

World layout runs as a "U": A → D down the first column, E → G up the second, so the camera's
return to A is short. Minimum in-frame text height is enforced by the per-state zoom (2.36–2.62).
